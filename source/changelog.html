Changelog

1.1.3

  • Refreshes the bundled compounds/SMILES snapshot for the ILThermo 2.0 update reported on July 22, 2026 (3,762 compounds, all with SMILES).

  • Uses the property-list API metadata to detect the last database update, instead of scraping the JavaScript-driven homepage.

  • Handles missing SMILES without leaking NaN into lookup dictionaries, and adds the verified L-aspartate/cholinium SMILES annotation.

  • Corrects eight manually reviewed SMILES assignments (four associations affected by reused ILThermo compound IDs, three metal complex ligands, and one morpholinium alkyl-chain length).

  • Normalizes the ILThermo API URL paths, removing accidental double slashes.

  • Reviews and refreshes the cookbook, including property-key examples, a dated data-snapshot notice, and the guanidinium-motif substructure-search example.

  • Updates the package date (October 16, 2026), version and documentation configuration, and fixes the documentation deployment workflow typo.

  • No changes to the public search API or runtime dependency list.

1.1.2

  • Refreshes public-facing documentation and package metadata after the move to the muCommons GitHub organization.

  • Updates repository, documentation, issue-tracker, and changelog links to the new public locations.

  • Clarifies project status: ILThermoPy is an unofficial ILThermo 2.0 access/enrichment package, is external-service-dependent, and is not affiliated with or endorsed by NIST.

  • Updates PyPI-facing metadata, including the short description, keywords, project URLs, and development-status classifier.

  • Adds citation metadata via CITATION.cff to prepare the repository for Zenodo release archiving.

  • No runtime-code changes, public API changes, or dependency changes.

1.1.1

  • Adds small code fixes.

  • Migrates package info from setup.cfg to pyproject.toml.

  • Changes layout to src.

  • Adds tests.

1.1.0

  • Updates stored structural data (up to June 4, 2024).

  • Renames the GetCompounds function to ilthermopy.compound_list.GetSavedCompounds().

  • Adds functionality for semi-automatic update of structural information of ILThermo compounds.

1.0.0

First release.
